# Section Spec: FOOTER

> Generated by /plan-section. Review and edit before building.

## Product Context
- **Job:** Close the experience with quiet confidence — the last impression before the visitor leaves or scrolls back up. No selling, no convincing. Just the maker's mark.
- **Content Hierarchy:**
  1. Social links (GitHub, LinkedIn, Instagram — the only actionable elements)
  2. "0 templates. 0 plugins. Handbuilt." (the brand statement)
  3. Colophon text (craft signature in tailoring voice)
  4. Copyright (legal necessity, visually invisible)
  5. Signature easter egg ("— GM" revealed on hover — the tailor's hidden mark)
- **Emotional Arc Position:** After the Contact form. The visitor has either submitted a fitting request or decided not to. Either way, the footer is the jacket's inside lining — the private label that only the wearer sees. Quiet, confident, signed.
- **Tailoring Metaphor:** The colophon — the label sewn inside the jacket lining. In bespoke tailoring, the colophon is the maker's signature: house name, date, fabric details. Here it names the process in craft language. The signature easter egg is the tailor's hand-stitched initials hidden inside the breast pocket.

## Design Direction

### Layout
- Garment tag ("COLOPHON") top-left, standard `.garment-tag` + `.tag-enter` classes
- No `section-wrapper` — footer keeps its own `max-width: 1100px` padding (slightly tighter than sections, appropriate for a subordinate element)
- Two-row structure:
  - **Row 1 (`.footer-top`):** Copyright left, social links right
  - **Row 2:** "Handbuilt" statement, then colophon text below it
- Everything left-aligned — no centering. The footer reads like a label sewn into the left side of a jacket lining.

### Social Links
- GitHub, LinkedIn, Instagram — inline SVG icons at 20×20
- Rest state: `--color-text-faint` at 0.4 opacity
- Hover: `--color-amber` at full opacity, 0.3s ease
- Focus-visible: amber outline (2px offset), opacity 1
- Explicit `aria-label` attributes: `"GitHub profile"`, `"LinkedIn profile"`, `"Instagram"`
- URLs from CONFIG object (no hardcoded URLs)

### Colophon Text
- **"Handbuilt" line:** "0 templates. 0 plugins. Handbuilt." — Outfit 0.65rem, `--color-text-faint` at 0.4 opacity
- **Colophon line:** "Measured, cut, and stitched by hand." — Outfit 0.6rem, `--color-text-faint` at 0.35 opacity
  - **No font names.** The old "Set in Space Grotesk and Inter" was wrong (site uses Syne + Outfit) and broke the craft voice. Dropped entirely.
  - **No "Built with Next.js."** Every other line in this footer is about craft, not tools. A tech credit in the middle of a craft statement breaks voice. The stack is visible in the Work section and GitHub. For the source-code curious, add an HTML comment in `<head>`: `<!-- Built with Next.js, React 19, TypeScript. Syne + Outfit. -->` — a second easter egg.
- **Copyright:** "© 2026 Grant Mahn" — Outfit 0.75rem, `--color-text-faint` at 0.5 opacity

### Signature Easter Egg — Enhanced
The signature "— GM" is the tailor's initials hidden inside the lining.

1. **Reveal trigger:** Hover `.footer-colophon` for **1.5 seconds** (CSS `transition-delay: 1.5s`)
2. **Reveal animation:** Stitch-draw effect:
   - `— GM` fades to `--color-amber` over 0.6s
   - Simultaneously, `::after` underline draws left-to-right (width 0 → 100%, 0.8s, `cubic-bezier(0.16, 1, 0.3, 1)`)
   - Underline: 1px, `--color-amber` at 0.5 opacity, ~120% text width
3. **Exit:** Everything fades out together over 0.3s. Unified exit.
4. **Implementation:** Pure CSS transitions + delays. No JavaScript.
5. **Reduced motion:** Instant reveal on hover, no delay, no draw.

### Entrance Animation
- Garment tag: `.tag-enter` class, IntersectionObserver adds `.visible`
- Footer content: `.fade-in` class, single fade-up, no stagger

### Fabric Texture
- **Twill** — 45deg diagonal repeating-linear-gradient (already implemented)
- `.footer::before`, full-viewport width, `z-index: -1`, `isolation: isolate`

### Typography

| Element | Font | Size | Weight | Extra |
|---------|------|------|--------|-------|
| Garment tag | Outfit | 0.68rem | 500 | uppercase, letter-spacing per global style |
| Copyright | Outfit | 0.75rem | 400 | `--color-text-faint`, opacity 0.5 |
| Social icons | — | 20×20 SVG | — | `--color-text-faint`, opacity 0.4 |
| Handbuilt statement | Outfit | 0.65rem | 400 | `--color-text-faint`, opacity 0.4 |
| Colophon | Outfit | 0.6rem | 400 | `--color-text-faint`, opacity 0.35 |

### Spacing
- Padding: `2.5rem 1.5rem`
- `1rem` between `.footer-top` and handbuilt line
- `0.35rem` between handbuilt and colophon lines

### Mobile (≤768px)
- `.footer-top` wraps — copyright stacks above social links
- Signature easter egg: remains hidden (no hover on mobile). No tap-and-hold equivalent.
- Twill texture at 0.5 opacity

### Reduced Motion
- `.fade-in` shows immediately (global styles)
- Signature: instant reveal, no delay, no draw

## Success Criteria
1. Garment tag "COLOPHON" with `.garment-tag` + `.tag-enter`, revealed by IntersectionObserver
2. Copyright left, social links right in `.footer-top`
3. Social links hover to amber, `focus-visible` with amber outline + opacity 1
4. Social links: `aria-label="GitHub profile"`, `"LinkedIn profile"`, `"Instagram"`
5. "0 templates. 0 plugins. Handbuilt." at 0.65rem, faint
6. Colophon: "Measured, cut, and stitched by hand." — no font/framework names
7. HTML comment in `<head>`: `<!-- Built with Next.js, React 19, TypeScript. Syne + Outfit. -->`
8. Signature: 1.5s hover delay → amber + thread-pull underline
9. Signature underline: 1px, amber 0.5 opacity, 0.8s draw
10. Exit: unified 0.3s fade
11. Twill texture via `.footer::before`
12. `.fade-in` entrance, no stagger
13. Reduced motion: instant signature reveal
14. Mobile: graceful wrap, no overflow

## Anti-Patterns
1. No section nav links — nav bar handles navigation
2. No "Back to Top" button
3. No decorative divider — `SectionDivider` handles this
4. No social link text labels — icons only, aria-label for a11y
5. No font/framework names in visible text
6. No attention-grabbing animation — the footer whispers
7. No mobile tap-and-hold for signature easter egg

## Do Not Touch
- The CONFIG object and social URLs
- The `SectionDivider` above the footer
- The twill texture pattern and opacity
- The "0 templates. 0 plugins. Handbuilt." copy
- "Measured, cut, and stitched by hand"
