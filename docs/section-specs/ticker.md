# Section Spec: TICKER

> Generated by /plan-section. Review and edit before building.

## Product Context
- **Job:** Reinforce technical credibility through a subliminal, always-moving stream of concrete credentials — the visitor absorbs competence without being "sold to."
- **Content Hierarchy:**
  1. Credential items (the text fragments themselves)
  2. Motion (continuous scroll communicates volume/depth)
  3. Amber color association (links credentials to the brand thread)
- **Emotional Arc Position:** Palate cleanser between Suit Spec Sheet (technical depth) and Services (offering). Low-effort section — the visitor rests while credentials wash past peripherally.
- **Tailoring Metaphor:** A tailor's measuring tape — the continuous ribbon of numbers and markings that runs endlessly through every fitting. The ticker is the tape measure stretched across the page.

## Design Direction

### Layout
- Full-bleed horizontal strip, no section padding beyond vertical breathing room
- No `SectionDivider` above or below (the ticker IS the divider)
- `<div>` not `<section>` — this is decorative, not a navigable landmark
- Two duplicate `<span>` elements for seamless CSS loop (translateX -50%)

### Fabric Texture
- **None.** Per CLAUDE.md: "SKIP — too narrow for pattern to register."

### Background Layers
1. Inherits page `--color-bg` (#080808) — no additional background

### Edge Treatment
- Horizontal fade mask: `mask-image: linear-gradient(to right, transparent, black 8%, black 92%, transparent)` — content dissolves at edges, no hard crop

### Animation
- Pure CSS `@keyframes ticker-scroll` — translateX(0) → translateX(-50%)
- Duration: 40s, linear, infinite
- No GSAP dependency (this section stays lightweight)
- No pause-on-hover (the tape measure doesn't stop)

### Typography
- Font: Outfit (body/`--font-body`)
- Size: 0.7rem
- Weight: 500
- Transform: uppercase
- Letter-spacing: 0.15em
- Color: `--color-amber` at 0.28 opacity
- White-space: nowrap

### Content
Current ticker string:
```
THOMPSON SAMPLING ML · 37+ DATABASE TABLES · 5,300+ PASSING TESTS · 15+ CRM INTEGRATIONS · KUBERNETES · GDPR COMPLIANT · BEHAVIORAL CLUSTERING · CANARY DEPLOYMENTS · REDIS/BULLMQ · CI/CD PIPELINE
```
Items are separated by ` · ` (middot with spaces). The full string is duplicated in two `<span>` elements for seamless looping.

### Spacing
- Vertical padding: `2rem 0` on `.ticker-section`
- Internal padding-right on each content span: `3rem` (gap before loop restart)

## Success Criteria
1. Ticker scrolls continuously left-to-right with no visible seam or jump at the loop point
2. Text is amber at reduced opacity — legible on close inspection but does not compete with adjacent sections
3. Edge mask fades content to transparent on both sides (no hard text clipping)
4. No layout shift or overflow — `overflow: hidden` on the section, `width: max-content` on the track
5. No GSAP or JS dependency — pure CSS animation only
6. Section uses `<div>` not `<section>` (not a landmark)
7. No `SectionDivider` above or below
8. No fabric texture background applied
9. On mobile (≤640px): ticker remains functional, text size does not change, motion continues
10. Credential items are factual and map to real capabilities from the Revenue OS project

## Anti-Patterns
1. No hover effects or interactivity — this is ambient, not interactive
2. No fade-in entrance animation — the ticker should already be scrolling when it enters the viewport
3. No gradient background or glow behind the ticker strip
4. No icons, logos, or images mixed into the credential items
5. No variable speed, easing, or bounce — strictly linear perpetual motion
6. No "skills" section energy — this is not a skill bar or tag cloud

## Do Not Touch
- The `TICKER_TEXT` constant content (update only with user approval of new credentials)
- The CSS-only animation approach (no migration to GSAP)
- The dual-span seamless loop technique

## Dependencies
- `--color-amber` and `--font-body` CSS custom properties from globals.css
- Sits between Suit Spec Sheet (section 3) and Services (section 5) in DOM order
