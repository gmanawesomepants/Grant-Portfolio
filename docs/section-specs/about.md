# Section Spec: ABOUT

> Generated by /plan-section. Review and edit before building.

## Product Context
- **Job:** Deliver the emotional reveal — the visitor realizes the entire site's tailoring language is autobiographical, not just a metaphor.
- **Content Hierarchy:**
  1. The closer line: "Former tailor. Same discipline, different material." (THE REVEAL)
  2. Bio paragraph — self-taught, no degree, real production systems
  3. Photo with garment-tag label
  4. Garment tag section label ("ABOUT")
- **Emotional Arc Position:** Section 6 of 9. The visitor has seen the work, the blueprint, the credentials ticker, the services. They've been swimming in tailoring language for 30+ seconds. This is where the metaphor lands — the "oh, he was ACTUALLY a tailor" moment. Everything before this retroactively gains weight.
- **Tailoring Metaphor:** This section IS the metaphor made literal. The photo is pinned to a mood board like a fabric swatch. The closer line is the stitch that pulls every thread together. The bird's eye texture underneath is a classic suiting weave — subtle diamond dots felt but not consciously seen.

## Design Direction

### Layout
- Two-column flex: text left (flex: 1 1 480px), photo right (flex: 0 0 280px)
- Gap: 3rem
- Mobile: stacks to single column, photo below text
- No visual section heading. The garment tag alone labels the section. The closer line carries the weight — no heading should compete with it. The closer line is a semantic `<h2>` for screen reader navigation, but styled identically to body text (Syne 1rem/600).

### Fabric Texture
- **Pattern:** Bird's eye (overlapping diagonal gradients + radial dots — diamond-like micro-texture)
- **Implementation:** CSS repeating-linear-gradient + radial-gradient (current implementation, kept as-is)
- **Opacity:** ~2-3% via color-mix

### Background Layers (back to front)
1. `--color-bg` (#080808) — base
2. Bird's eye texture at ~2-3% opacity via `::before`
3. Content (text + photo)

### Photo Treatment
- 280x380px placeholder (or real portrait when available)
- `background: var(--color-bg-elevated)` for placeholder state
- `border-top: 2px solid var(--color-amber-dim)` — fabric swatch pin-strip
- `transform: rotate(1.5deg)` — casually pinned to mood board, not grid-locked
- Amber dot "pin" at top-left (5px circle, absolute positioned)
- Garment tag below photo: "Grant Mahn - Founder"

### Animations
- `.fade-in` on `.about-layout` via IntersectionObserver (no GSAP)
- `.tag-enter` on garment tag

### Typography

## Success Criteria
1. The closer line ("Former tailor. Same discipline, different material.") is visually distinct from the bio paragraph — different font (Syne), heavier weight, full white color.
2. The closer line triggers a recontextualization moment — it should feel like a reveal, not just another sentence. Whitespace and contrast do the work; no gimmicky animation.
3. The photo frame reads as a mood-board swatch pinned at an angle, not a generic avatar circle or square.
4. The bird's eye fabric texture is subliminal — visible only on close inspection (~2-3% opacity).
5. Mobile layout stacks cleanly — text first, photo second, no horizontal overflow.
6. The section uses NO GSAP — entrance animations are CSS-only via IntersectionObserver.
7. The bio text stays within max-width 560px and doesn't stretch to full container width on large screens.
8. The amber pin dot is visible but subtle — it anchors the mood-board metaphor without drawing focus.

## Anti-Patterns
1. **No circular avatar crop.** This is LinkedIn, not a bespoke portfolio.
2. **No skill bars, tech badges, or icon grids.** The bio speaks; no decoration needed.
3. **No timeline or career history.** The reveal only works because it's terse. "Former tailor." — that's it. Don't explain it.
4. **No animated text reveal or typewriter effect on the closer line.** The line earns its impact from 30 seconds of prior context, not from animation.
5. **No gradient overlay or decorative blur on the photo.** Clean edges, like a real pinned fabric swatch.
6. **No "read more" or expandable content.** If it's not worth showing, cut it. Don't hide it.
7. **No testimonials, social proof, or third-party quotes.** One voice. One person. One craft.

## Do Not Touch
- The closer line text: "Former tailor. Same discipline, different material."
- The Syne + Outfit font pairing
- The dark/amber color relationship
- The garment-tag component styling
- The fade-in / tag-enter animation class behavior
- The rotate(1.5deg) photo tilt and pin treatment
